        Typical pipeline command:

  nextflow run sanger-tol/treeval -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input          [string]  Path to YAML file describing the input data. 
  --outdir         [string]  The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --juicer         [boolean] If false then turn off Juicer generation 
  --binfile        [boolean] If false then turn off bin file generation 
  --split_telomere [boolean] Split the telomere file into 5' and 3' files for seperate ingestion into the HiC maps [default: 
false]  
  --steps          [string]  A csv list of steps to skip 
  --email          [string]  Email address for completion summary. 
  --mode           [string]  Run mode specified (FULL, RAPID, RAPID_TOL, JBROWSE, FULL_COMBINED)  (accepted: FULL, RAPID, 
RAPID_TOL, JBROWSE, FULL_COMBINED)  
  --run_hires      [boolean] Run HiRes pretext maps 
  --run_ultra      [boolean] Run UltraRes pretext maps 
  --kmer_length    [integer] Length of kmer for FASTK analysis [default: 31] 

Generic options
  --help           [boolean, string] Display the help message. 
  --help_full      [boolean]         Display the full detailed help message. 
  --show_hidden    [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
