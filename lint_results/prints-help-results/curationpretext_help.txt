        Typical pipeline command:

  nextflow run sanger-tol/curationpretext -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.

Input/output options
  --input                  [string]  Input fasta file 
  --split_telomere         [boolean] Split the telomere file into 5' and 3' files for seperate ingestion into the HiC maps [default: 
false]  
  --run_coverage           [boolean] Run and ingest the coverage analysis. [default: true] 
  --run_telomere           [boolean] Run and ingest the telomere analysis. [default: true] 
  --run_gap                [boolean] Run and ingest the gap analysis. [default: true] 
  --run_repeats            [boolean] Run and ingest the repeats analysis. [default: true] 
  --run_busco              [boolean] Run and ingest the BUSCO analysis. [default: false] 
  --run_pebble             [boolean] Run and ingest the Pebble coverage analysis. [default: false] 
  --no_tracks              [boolean] Do not generate tracks. [default: false] 
  --reads                  [array]   Input longread fasta files 
  --read_type              [string]  Type of longread data  (accepted: hifi, clr, ont, illumina) [default: hifi] 
  --cram                   [array]   Input cram files 
  --teloseq                [string]  Telomeric Motif for search. Defaults to TTAGGG [default: TTAGGG] 
  --map_order              [string]  HiC map scaffold order. Default to unsorted  (accepted: length, unsorted) [default: unsorted] 
 
  --aligner                [string]  Aligner for use {minimap2, bwamem2} in generating map  (accepted: bwamem2, minimap2, AUTO) 
[default: AUTO]  
  --generate_track_indexes [boolean] Generate track indexes [default: false] 
  --run_hires              [boolean] Run High Resolution pretext maps [default: true] 
  --run_ultra              [string]  Run Ultra resolution pretext maps  (accepted: yes, no, force) [default: no] 
  --cram_chunk_size        [integer] Chunk size for splitting CRAM files [default: 10000] 
  --pre_mapped_bam         [string]  Pre-mapped BAM file 
  --snapshot_order         [string]  Order of scaffolds in the png 
  --snapshot_generation    [boolean] Generate a snapshot of the pretext output [default: true] 
  --snapshot_annotation    [boolean] Annotate the pretext snapshot [default: false] 
  --juicer_generation      [boolean] Generate a juicer map output [default: false] 
  --outdir                 [string]  The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                  [string]  Email address for completion summary. 
  --sample                 [string]  A Name for the sample 
  --all_output             [boolean] Output all files [default: false] 
  --multi_mapping          [number]  MAPQ values used to filter reads. [default: 0] 
  --replace_dots           [boolean] Replace dots in FASTA headers with underscores. [default: false] 
  --mapping_statistics     [boolean] Generate mapping statistics. [default: false] 

Generic options
  --help                   [boolean, string] Display the help message. 
  --help_full              [boolean]         Display the full detailed help message. 
  --show_hidden            [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
