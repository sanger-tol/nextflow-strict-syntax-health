Input/output options
  --input                             [string] Path to YAML file describing the input data. (This parameter has sub-parameters. Use '--help 
input' to see all sub-parameters) 
  --outdir                            [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure. (This parameter has sub-parameters. Use '--help outdir' to see all 
sub-parameters) 
  --email                             [string] Email address for completion summary. (This parameter has sub-parameters. Use '--help email' 
to see all sub-parameters) 

Assembly options
  --assembler                         [string]  Which assembler to use for metagenome assembly.  (accepted: metamdbg, myloasm) [default: 
myloasm] (This parameter has sub-parameters. Use '--help assembler' to see all sub-parameters) 
  --tiara_exclude_classifications     [string]  A comma-separated list of tiara classifications to use to exclude contigs from the assembly. Options 
are 'bacteria', 'archaea', 'prokarya', 'eukarya', 'organelle' or 'unknown'. (This parameter 
has sub-parameters. Use '--help tiara_exclude_classifications' to see all sub-parameters) 
  --enable_genomad                    [boolean] Enable Genomad for classification of circular contigs for determination of plasmid status. 
[default: true] (This parameter has sub-parameters. Use '--help enable_genomad' to see all 
sub-parameters) 
  --genomad_db                        [string]  Path to a directory containing a Genomad database. If not provided, the database will be downloaded 
automatically. (This parameter has sub-parameters. Use '--help genomad_db' to see all 
sub-parameters) 
  --genomad_splits                    [integer] The number of chunks to split the Genomad database into when running searches. Increasing this value 
decreases memory usage at the expense of runtime. [default: 1] (This parameter has 
sub-parameters. Use '--help genomad_splits' to see all sub-parameters) 

Read mapping options
  --long_read_mapping_reads_per_chunk [integer] When mapping long reads, how many long reads to map to the assembly in a single chunk. [default: 
1000000] (This parameter has sub-parameters. Use '--help long_read_mapping_reads_per_chunk' to 
see all sub-parameters) 
  --minimum_hifi_perc_identity        [integer] The minimum required percent identity of a read mapping to the assembly to be counted during 
coverage estimation for MetaBat2 and MaxBin2. [default: 99] (This parameter has 
sub-parameters. Use '--help minimum_hifi_perc_identity' to see all sub-parameters) 
  --hic_aligner                       [string]  Which Hi-C aligner to use - either bwa-mem2 or minimap2.  (accepted: bwamem2, minimap2) 
[default: bwamem2] (This parameter has sub-parameters. Use '--help hic_aligner' to see all 
sub-parameters) 
  --hic_mapping_cram_slices_per_chunk [integer] When mapping Hi-C, map each CRAM file in slices of this size. [default: 10000] (This 
parameter has sub-parameters. Use '--help hic_mapping_cram_slices_per_chunk' to see all 
sub-parameters) 
  --hic_mapping_minq                  [integer] Minimum map quality for a Hi-C read to be passed on for binning by Metator. [default: 10] 
(This parameter has sub-parameters. Use '--help hic_mapping_minq' to see all sub-parameters) 
  --save_bams                         [boolean] Save the mapped BAM files to the output directory. (This parameter has sub-parameters. Use 
'--help save_bams' to see all sub-parameters) 

Binning options
  --enable_binning                    [boolean] Enable binning of metagenomes into genome bins. [default: true] (This parameter has 
sub-parameters. Use '--help enable_binning' to see all sub-parameters) 
  --enable_multisplit                 [boolean] Enable multi-split binning modes when binning with SemiBin2 or VAMB. (This parameter has 
sub-parameters. Use '--help enable_multisplit' to see all sub-parameters) 
  --minimum_contig_size               [integer] The minimum size of contig to be considered when binning. [default: 3000] (This parameter 
has sub-parameters. Use '--help minimum_contig_size' to see all sub-parameters) 
  --maximum_contig_size               [string]  The maximum size of contig to be considered when binning. (This parameter has 
sub-parameters. Use '--help maximum_contig_size' to see all sub-parameters) 
  --minimum_bin_size                  [integer] The minimum size of a bin, in basepairs, to be emitted. [default: 150000] (This parameter 
has sub-parameters. Use '--help minimum_bin_size' to see all sub-parameters) 
  --extract_circular_contigs          [boolean] Extract circular contigs and treat them as bins. [default: true] (This parameter has 
sub-parameters. Use '--help extract_circular_contigs' to see all sub-parameters) 
  --minimum_circular_contig_length    [integer] The minimum length of a circular contig required to be treated as a bin. [default: 250000] 
(This parameter has sub-parameters. Use '--help minimum_circular_contig_length' to see all 
sub-parameters) 
  --enable_metabat2                   [boolean] Enable binning with Metabat2. [default: true] (This parameter has sub-parameters. Use 
'--help enable_metabat2' to see all sub-parameters) 
  --enable_maxbin2                    [boolean] Enable binning with MaxBin2. (This parameter has sub-parameters. Use '--help enable_maxbin2' 
to see all sub-parameters) 
  --enable_comebin                    [boolean] Enable binning with Comebin. [default: true] (This parameter has sub-parameters. Use '--help 
enable_comebin' to see all sub-parameters) 
  --enable_semibin2                   [boolean] Enable binning with Semibin2 in single-sample mode. [default: true] (This parameter has 
sub-parameters. Use '--help enable_semibin2' to see all sub-parameters) 
  --enable_vamb                       [boolean] Enable binning with VAMB. [default: true] (This parameter has sub-parameters. Use '--help 
enable_vamb' to see all sub-parameters) 
  --enable_taxvamb                    [boolean] Enable taxonomic classification of assembled contigs with centrifuger. These are passed to VAMB to 
enable its taxonomic binning mode. (This parameter has sub-parameters. Use '--help 
enable_taxvamb' to see all sub-parameters) 
  --centrifuger_db                    [string]  Path to a centrifuger <prefix>.1.cfg file. The other files are detected automatically. (This 
parameter has sub-parameters. Use '--help centrifuger_db' to see all sub-parameters) 
  --enable_metator                    [boolean] Enable binning with MetaTor. [default: true] (This parameter has sub-parameters. Use '--help 
enable_metator' to see all sub-parameters) 
  --hic_enzymes                       [string]  A comma-separated list of Hi-C enzymes to use for binning with MetaTOR. (This parameter has 
sub-parameters. Use '--help hic_enzymes' to see all sub-parameters)

  --gtdbtk_place_species              [boolean] Skip the ANI screen check with skani when classifying genomes with GTDB-Tk. (This parameter

  --gtdb_bac120_metadata              [string]  Path to the GTDB-Tk bac120 metadata file. [default:

  --gtdbtk_min_completeness           [integer] Minimum CheckM2 completeness required for a bin to be classified by GTDB-Tk. [default: 50]

  --gtdbtk_max_contamination          [integer] Maximum contamination allowed CheckM2 completeness for a bin to be classified by GTDB-Tk.
